# Sexy: Unified Design Intelligence Rules

When working on UI, design, frontend styling, animations, or layouts in this workspace:

1. **Activate the Unified Pipeline**: Combine the strengths of the 6 design engines into a single fluid workflow:
   - Tokens & Architecture: Use `design-md` and `ui-ux-pro-max` design systems.
   - Character & Direction: Follow `hallmark` to ensure human, distinct, non-generic designs.
   - Motion & Staging: Follow `scroll-craft` for hero depth and scroll kinetics.
   - Micro-Details: Apply `make-interfaces-feel-better` rules (concentric border radii, font smoothing, spring curves, tabular numbers).
   - Final Craft Floor: Apply `impeccable` design director standards before committing UI code.

2. **No Conflicts**:
   - Do not mix conflicting animation libraries or redundant styling frameworks. Honor the project's existing stack (Tailwind, CSS Modules, or Styled Components).
   - If a specific design spec (like a `DESIGN.md`) is provided, that spec overrides generic aesthetic presets.
